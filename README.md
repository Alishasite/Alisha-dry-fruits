## 📖 About The Project

**DryFruit Delight** is a single-page website that presents information about premium dry fruits. It includes product cards, health benefits, and a contact section — all designed with a clean, warm, and natural colour theme.

This project was built to practise:

- Semantic HTML5 structure
- External CSS styling
- Responsive layout with Flexbox and Grid
- Publishing a project on GitHub

---

## ✨ Features

- 🎨 Warm cream and brown colour theme
- 📱 Fully responsive (mobile, tablet, desktop)
- 🧭 Sticky navigation bar with smooth scroll
- 🥜 Six product cards with prices and tags
- 💪 Health benefits section
- 📬 Contact form layout
- ⚡ Hover effects and smooth transitions
- 🌿 Semantic HTML tags

---

## 🛠️ Built With

- **HTML5** — structure and semantic elements
- **CSS3** — styling, Flexbox, Grid, media queries, transitions

> No JavaScript or CSS framework was used. This project focuses on core web fundamentals.
